# Com contribuir

1. Assigna't una issue (o comenta "M'ho quedo").
2. Fes un fork del repositori.
3. Crea el fitxer `termes/nom-del-terme.md` copiant la plantilla.
4. Obre una PR amb el títol "Afegeix terme: <nom>" i escriu `Closes #<número>`.
5. Una PR = un terme. No editis fitxers d'altres companys.
